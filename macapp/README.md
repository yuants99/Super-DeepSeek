# DeepSeek（macOS App）

把 `chat-demo` 的静态构建物包成一个原生 macOS App：**AppKit 窗口 + WKWebView**，
直接以 `file://` 加载 App 包内的网页。**不启动任何本地服务、不监听任何端口。**

```
macapp/
├── App.swift        # WKWebView + 菜单/权限/下载
├── Info.plist       # bundle id、麦克风用途说明
├── build.sh         # 编译、嵌入 dist、ad-hoc 签名
└── build/DeepSeek.app
```

## 图标

`AppIcon.icns` 是脚本矢量绘制的原创图标（不是 emoji，也没有沿用官方鲸鱼造型）：
深海军蓝圆角底、薄荷绿鲸鱼、腹部浅色、上翘尾鳍与气泡水花。预览见 `icon-preview.png`。

重新生成：

```sh
swift make_icon.swift icon.iconset
iconutil -c icns icon.iconset -o AppIcon.icns
rm -rf icon.iconset
```

`build.sh` 在 `AppIcon.icns` 缺失时会自动执行上面的步骤。

## 构建

```sh
cd ../chat-demo && pnpm build      # 先产出 dist
cd ../macapp && ./build.sh         # 再打包 App
```

产物：`build/DeepSeek.app`（约 4.7 MB，可直接拖到「应用程序」）。

## 打包 DMG（分发用）

```sh
./build.sh          # 先产出 App
./make_dmg.sh       # 生成 build/DeepSeek 1.0.dmg
```

DMG 打开后是一个 660×400 的安装窗口：左侧 App、右侧 Applications 快捷方式，
中间箭头，底部写明“右键 → 打开”的首次启动方式和数据位置。背景由 `make_dmg_bg.swift`
生成（1x + @2x，dmgbuild 自动合成 HiDPI TIFF）。

> 未做公证；对方第一次打开需要右键 → 打开（或在“系统设置 → 隐私与安全性”里放行）。

## 运行与自检

```sh
open "build/DeepSeek.app"

# 无窗口自检：打印 origin、isSecureContext、IndexedDB 是否可用/是否持久化、首屏文字
"build/DeepSeek.app/Contents/MacOS/DeepSeekChat" --selftest

# 下载链路自检（不弹保存面板）
DS_DOWNLOAD_DIR=/tmp/ds-download "build/DeepSeek.app/Contents/MacOS/DeepSeekChat" --selftest-download
```

`--selftest` 会输出 `prev` 与 `now`：连续运行两次，第二次的 `prev` 等于第一次的 `now`，
即证明 IndexedDB 跨启动持久化。

## 为什么可以直接 `file://`

- WKWebView 的 `file://` 页面是安全上下文（`isSecureContext = true`），`getUserMedia` 可用；
- WebKit 在 `file://` 下有可用的持久化 IndexedDB，会话与附件能正常保存；
- 实测把 App 复制到别的路径再启动，数据仍在（存储按 bundle id 归属，不随路径变化）。

因此不需要本地 HTTP 服务：没有端口、没有监听，其他本机程序无法连进来。

## 存储

```
~/Library/WebKit/local.deepseek.chat
```

- 与 Safari/Chrome 完全隔离；导入历史需要在这个 App 里做一次。
- 移动 App 位置不影响存储（按 bundle id 归属）。
- 删除该目录 = 清空 App 内全部对话与附件。

## 模型设置

设置 → 模型设置里有五个子页：系统提示词（可改、可恢复默认、最多 5 个预设，均限 500 字）、
安全审核（默认关闭，可设 low/high）、采样参数（总开关 + temperature/top_p/top_k/max_tokens）、
模型切换（deepseek-flash / deepseek-v4-pro）、latest_reminder（日期/星期可手动覆盖，地点自由填写，
客户端固定 Web，语言中英文）。

## 输入框快捷控制与计费中心

- 输入框快捷区：思考（关闭 / low / high / max）、联网、系统提示词（默认 / 预设 / 编辑）、
  安全审核（图标底色：无填充=关、淡绿=低、淡红=高）、API Key 切换；窗口变窄时自动折叠为
  「思考 + 展开」，也可手动收起。
- 支持多个 DeepSeek API Key（标签 + 快速切换，设置 → 数据管理里增删改）。
- 设置 → 计费中心：账户余额（多 Key 可选、进入自动查询、显示查询中）、近 7/14/30 天的每日 Token
  与花费图表、缓存命中/未命中/输出明细、高峰与空闲拆分，按官方价格（含峰谷价）估算；
  底部提供「前往充值 / 开放平台」链接。导入的历史归档没有分项用量，统计从本机新消息开始。
- 模型设置里的「提醒」子页已更名为「用户元数据」。
- 数据管理新增「清除所有数据」：10 秒倒计时后由 macOS 原生清空全部 WebKit 来源、旧 127.0.0.1、
  缓存、HTTPStorages 与偏好文件，随后退出 App；重新打开为完全全新状态。
- 会话菜单新增「对话设置」：按分组管理本对话的思考/联网/安全/Key、系统提示词与个性化，
  顶部展示轮数、Token、工具调用与总消费；修改自动保存。
- 通用设置新增自定义欢迎语，可一键还原默认。
- 思考/联网/系统提示词/安全/API Key 改为每个对话独立保存；新建对话沿用最近一个对话，
  启动时也使用最近对话的设定。
- 统计行默认显示，输入框按钮行尾部箭头控制显示并记忆；Token 显示纯数字与本对话累计费用。
- 左下角新增平峰/高峰标签（淡绿/淡蓝），悬浮查看当前时段输入/输出价格。
- 移除“内容由 AI 生成”提示；App 图标改为亮色原创鲸鱼。
- 首页品牌区为加大号的 DeepSeek 字标 + Powered By DeepSeek Platform 角标；应用名统一为 DeepSeek。
- 归档支持可选密码保护（PBKDF2 + AES-GCM，至少 6 位）：完整历史与单会话导出均可加密，
  导入时自动识别并提示解密；不设密码时仍为普通 ZIP。
- 会话列表：每个对话菜单新增「导出对话」（单会话 ZIP）；列表顶部加号可导入单个对话，
  导入后以新 id 写入、创建/活跃时间设为导入时刻。
- 数据管理：导出改为向导（按最近活跃/创建时间/轮数分组、搜索、多选、可选是否包含图片）；
  导入改为向导（扫描归档、展示新增与冲突、逐项选择保留本地或覆盖、批量操作）。
- 设置导航新增独立的「API Key」分区，管理多个带标签的 Key。
- 输入框下方新增会话统计条：轮数/步数/速度、累计 Token 与缓存命中、上下文环形进度；
  三个浮窗分别展示生成耗时/TTFT/TPS、Token 分项、上下文与「压缩上下文」。
  压缩保留最近 6 轮，把更早轮次压成摘要随 system 重新注入，原始消息不删除；
  摘要会作为默认折叠的卡片插在对话里，点开可查看压缩产物。
- 压缩状态随导出归档保存（消息始终是完整原文），导入后仍可从压缩点继续；
  其他官方客户端会忽略该扩展字段，按完整历史导入。
- 本地 Token 计量采用官方换算（中文 ≈0.6、英文字符 ≈0.3），可用预算 = 1M − 80K 预留；
  70% / 85% / 95% 三档告警并变色，提示压缩。
- 模型设置新增「上下文」页：轻 / 均衡 / 激进三档压缩，只决定摘要长度（约输入 12% / 8% / 5%，上限
  6000 / 4000 / 2500 tokens）；压缩时把完整对话交给模型生成摘要，不再保留未压缩轮次。
- 统计条对本地估算的上下文显示「估算」气泡；服务端 usage 可用时不显示。
- 构建产物按 vendors/react/markdown 与设置面板分包，主包约 174K。
- 个性化：独立设置页，总开关 + 7 种风格 + 亲切/热情/标题列表/表情四档滑条（两列布局）+ 自定义指令；
  关闭时完全忽略。内容拼成前置指令追加在系统提示词之后（系统提示词优先），并随配置式保存。
- 语音输入：系统提示词、自定义指令等文本框均有麦克风，调用 DeepSeek ASR。
- 计费：除模型 Token 外，加入搜索/抓取（刊例价 5 元/千次）、ASR（0.78 元/小时）、
  TTS（3 元/万字符）、文件解析（1.5 元/千页）的说明与统计。
- 配置式：设置最顶级的独立设置空间（主题/语言/音色/位置/模型/Key，不含对话），可新建、切换、
  重命名、删除；导出可选是否包含 Key，文件用 PBKDF2 + AES-GCM 加密（密码至少 6 位），支持导入。
  侧栏底部改为图标设置按钮 + 配置式快速切换；原生菜单拆为「对话 / 模型 / 配置式 / 设置」。
- 计费中心按当前选中的 API Key 隔离展示；重置只清理该 Key 的本地统计。
- 隐私模式：首页右上角入口（中性提示条，不抢眼）；不落库、不计费、不可导出、关闭联网与安全审核，退出恢复原设置；
  数据管理可设“默认以隐私模式启动”。个性化新增“在隐私模式启用”开关。
- 首次启动无 Key 自动打开 API Key 页并只提示一次充值/获取 Key；余额低于 3 元启动提示（每天一次），
  402 时立即提示充值。
- 服务可用性：侧栏左下角状态图标，读取官方 status RSS（原生代取/浏览器直连）；
  弹窗按「API 对话 / 搜索与抓取 / 语音 / 文件」分服务展示，只显示一条当前或最近事件，不做日历。
- macOS 原生菜单联动：新增「对话」「设置」菜单，可切换思考档位、联网、系统提示词预设、模型、
  安全审核，打开任意设置页，新建对话、压缩上下文；勾选状态与 Web 双向同步。
  快捷键：⌘N 新对话、⌘, 设置、⌘⌥1–4 思考档位、⌘⇧L 联网、⌘⇧K 压缩上下文。

## 权限与原生行为

- **麦克风**：`NSMicrophoneUsageDescription` + `WKUIDelegate` 只对 `file://` 页面放行；
  首次语音输入时系统以本 App 身份弹授权。
- **外链**：正文链接、`target=_blank` 一律交给系统默认浏览器。
- **导出**：`<a download>` / Blob 下载通过 `WKDownloadDelegate` 走系统保存面板（已在 `file://` 下实测）。
- **上传**：文件选择走系统打开面板，可直接导入 DeepSeek 导出的 ZIP。
- **菜单**：⌘C/⌘V/⌘Z、⌘R 重载、⌘0/⌘+/⌘- 缩放、⌘W 关窗、⌘Q 退出。
- **窗口**：尺寸/位置自动记忆；关闭最后一个窗口即退出。
- **单实例**：同一 bundle 只保留一个实例，避免两个窗口同时写一份 IndexedDB。

## 已知限制

- ad-hoc 签名、未 notarize；本机运行没有问题，分发需自行签名/公证。
- 重新构建后二进制签名变化，macOS 可能重新询问一次麦克风权限。
- 网页资源是打包进去的：更新网页需要重新 `pnpm build` 并重新 `./build.sh`。
