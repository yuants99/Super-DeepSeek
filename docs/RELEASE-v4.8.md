# Super DeepSeek 4.8

非官方出品的 macOS DeepSeek 客户端，本地优先，支持个性化、长期记忆与每对话独立设置。

> Super DeepSeek 不是 DeepSeek 官方产品，与 DeepSeek 官方不存在隶属、授权或合作关系。
> 模型推理能力完全依赖 DeepSeek API；使用前请自备 API Key。

## 本次亮点

- **个性化**：7 种风格、4 档语气滑条与自定义指令，按配置式保存。
- **我的与长期记忆**：称呼、背景、位置与文章式记忆；支持「与记忆对话」和从对话中生成记忆总结。
- **每对话独立设置**：思考、联网、系统提示词、安全审核、API Key 分别跟随对话；新对话沿用最近设定。
- **配置式**：主题、语言、音色、位置、模型、Key、个性化与我的信息独立管理。
- **内置图片查看器**：点击图片即可在 App 内查看原图，支持滚轮缩放、拖拽平移、双击切换与保存。
- **客户端化交互**：输入框保留原生复制/粘贴菜单，其他区域不再弹出浏览器式右键菜单；禁用网页捏合缩放。
- **计费与状态**：多 Key 计费、缓存与峰谷拆分、服务可用性状态。
- **数据管理**：导入/导出向导、可选 AES-GCM 加密、全量抹除并提示退出。

## 安装

1. 下载 `Super DeepSeek 4.8.dmg`；
2. 打开 DMG，把 `Super DeepSeek.app` 拖到「应用程序」；
3. 首次打开请在 App 上右键 → **打开**（当前为 ad-hoc 签名，未做 Apple 公证）；
4. 在「设置 → API Key」填写自己的 DeepSeek API Key。

要求：Apple Silicon、macOS 12+。

## 已知限制

- 未公证；首次启动需要右键打开。
- 官方归档通常只包含图片；非图片附件可能只有元数据。
- 导入的历史消息通常没有 usage，旧对话计费统计从 0 开始。
- 旧版本中通过 `target=_blank` 打开图片会触发系统「未设定应用」弹窗；4.8 已改为内置查看器。
